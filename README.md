# LabBooker — PHP Research Equipment Booking System

LabBooker is a PHP + SQLite reservation system for university labs and research groups.

## Features
- Equipment inventory management
- Booking request workflow
- Date/time conflict detection
- Approve/reject booking requests
- Upcoming booking dashboard
- Email validation
- Prepared PDO queries
- Responsive UI
- Automatic SQLite setup

## Tech Stack
PHP 8+, SQLite, PDO, HTML5, CSS3

## Run Locally
```bash
php -S localhost:8001
```
Then open `http://localhost:8001`.

## Portfolio Talking Points
The booking workflow includes server-side validation and overlap detection to prevent double-booking. The application models a practical departmental workflow and demonstrates relational data handling, joins, CRUD operations, business rules, and status management in PHP.
